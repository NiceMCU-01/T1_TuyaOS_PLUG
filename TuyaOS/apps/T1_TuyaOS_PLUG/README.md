# T1 TuyaOS 插座应用

本仓库仅包含 TuyaOS Wi-Fi SoC T1 无计量插座/插排的应用层代码。通过构建期配置 `T1_PLUG_WAY_NUM`，可选择 1、2、3 或 4 路继电器通道。

应用包含继电器/通道控制、本地总控按键、Wi-Fi 配网指示、Tuya DP 处理、上电状态、童锁、倒计时与定时功能，以及 Beacon 遥控器控制等逻辑。

## 本仓库不包含的内容

本仓库**不是**完整的 TuyaOS SDK，也不是可直接量产的固件包。以下内容被有意排除：

- TuyaOS 开发框架、平台库、工具链、启动文件和固件构建产物。
- 产品 PID、Firmware Key、证书、量产凭据及其他产品专属敏感信息。
- 生成文件 `build/tuya_app.config` 和 `include/tuya_app_config.h`。

本仓库不授予 TuyaOS SDK 或其预编译组件的再分发许可。

## 使用前准备

1. 通过涂鸦官方或其他授权渠道获取匹配的 TuyaOS 产品开发框架。
2. 在 Visual Studio Code 中安装 **Tuya Wind IDE** 插件，并完成所需的授权、SDK 与构建环境准备。
3. 使用属于个人或所在公司的私有产品/构建配置。

## 放置应用目录

将本仓库中的 `T1_TuyaOS_PLUG` 应用目录复制到已授权的 TuyaOS 开发框架的 `apps/` 目录：

```text
<你的 TuyaOS 开发框架>/TuyaOS/apps/T1_TuyaOS_PLUG/
```

随后使用该开发框架正常的 Tuya Wind IDE / 构建配置流程生成应用配置并编译。

## 私有产品配置

构建前，必须在个人或公司私有的 TuyaOS 构建配置中提供自己的、已获授权的产品信息：

- 必须配置 `TY_PRODUCT_ID`。公开源码不包含可直接使用的产品 PID。
- Firmware Key、证书或其他凭据仅在自己的授权产品流程确有需要时配置。
- 不要将产品 PID、密钥、证书、Wi-Fi 凭据、产测数据、日志或生成的固件文件提交回本仓库。

在正常配置流程中使用 `T1_PLUG_WAY_NUM` 选择目标继电器路数（`1`、`2`、`3` 或 `4`）。配置重新生成时会产生 `include/tuya_app_config.h`；**禁止手工编辑该生成文件**。

公开默认配置下，产测 Wi-Fi 扫描保持关闭。任何产测行为仅应在私有产品环境中配置。

## 构建与验证说明

请使用匹配开发框架的官方构建流程。构建成功仅表示编译和打包通过；烧录与设备功能验证仍须单独完成。

## 提交或发布改动前

不要加入 TuyaOS SDK 二进制、工具链、启动文件、固件产物、产品凭据或内部项目记录。发布任何改动前，请复核第三方许可证及所有产品专属信息。
